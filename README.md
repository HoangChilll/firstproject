📌 Introduction

This project is a 2D platform game inspired by the classic Mega Man series. The game is fully developed using pure Java without external game engines. It demonstrates core game development concepts such as object-oriented design, collision detection, sprite animation, event handling, and game loop management.

The player controls MegaMan to navigate through levels, defeat enemies, avoid obstacles, and complete missions.

🚀 Features

Character movement (left, right, jump)

Shooting mechanics

Enemy AI behavior

Collision detection system

Health and scoring system

Multiple levels

Sprite animation and sound effects

🛠 Technologies Used

Java (Core Java)

Java AWT / Swing (for rendering and UI)

Object-Oriented Programming (OOP)

Event-driven programming

🎯 Learning Objectives

This project was built to:

Practice OOP principles (Inheritance, Polymorphism, Encapsulation)

Implement game loop and real-time rendering

Handle keyboard input events

Manage game state and collision logic

Improve Java programming skills through a practical application

▶ How to Run

Clone the repository

Open the project in your IDE (IntelliJ / Eclipse / NetBeans)

Run the main class file
